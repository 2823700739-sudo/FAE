### 与 P4-WIFI6-Touch-LCD-4B 的配置和功能差别

- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B、ESP32-P4-WIFI6-Touch-LCD-4B。
- **根因**：S3偏常规语音触控和整机电池应用；P4有更多处理/显示/摄像头及存储扩展资源，但不会因此让云端语音助手本身更聪明。
- **回复内容（解决方法）**：S3版为LX7双核最高240MHz、16MB Flash/8MB PSRAM、480×480 RGB屏，原生2.4GHz Wi-Fi/BLE，AXP2101管理3.7V整机锂电池，有QMI8658与PCF85063。P4版为高性能双核最高400MHz（仍需看实际revision）、32MB Flash/32MB PSRAM、720×720 MIPI-DSI屏，C6提供2.4GHz Wi-Fi6/BLE，另有15Pin CSI和MicroSD/USB HS；电池接口主要用于RTC备份，不是S3式整机充放电。两款均有多点触摸、ES7210/ES8311及麦克风/扬声器基础。常规触控、小智或电池终端可选S3；需摄像头、更多资源/复杂界面可评估P4。普通P4 4B不含RJ45/RS485/继电器，勿混同86-Panel-ETH-2RO。[S3规格](https://docs.waveshare.net/ESP32-S3-Touch-LCD-4B/)、[P4规格](https://docs.waveshare.net/ESP32-P4-WIFI6-Touch-LCD-4B/)。

### GPIO4 控制背光时，高低电平和 PWM 为 0 分别是什么状态
- **客户问题/现象**：拉高/拉低背光表现与直觉相反，亮度0仍有微光。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B、AP3032。
- **根因**：GPIO4经反馈端反相调光，不直接控制AP3032的CTRL使能；CTRL被100K上拉且未接MCU。
- **回复内容（解决方法）**：GPIO4 LOW为最亮、HIGH为最低/近似关闭；PWM占空比0%意味着恒低，反而最亮。官方亮度API采用 `duty = 100 - brightness`。要保证彻底关闭，需硬件增加NMOS/NPN把AP3032 CTRL拉低；不要直接操作高压背光端 `LED_A`。
- **相关报错/日志**：无。

### 新版必须按 PWRKEY，能否通电自动开机
- **客户问题/现象**：展厅安装在玻璃后，不便触摸电源键。

### 除 Type-C 和锂电池外能否从扩展口供电
- **客户问题/现象**：希望从H3排针给板卡长期供电。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B。
- **根因**：H3 Pin2 `VBUS`连接AXP2101 VBUS输入，Pin20为GND，与USB 5V处于同一电源网。
- **回复内容（解决方法）**：可以用稳定5V接H3-2、GND接H3-20，效果近似Type-C。不能接12/24V或从3.3V反向供电；确认奇偶排针与PCB镜像方向。不要同时连接多个USB/外部5V源，装电池时会进入充电状态，首次建议断开电池测试。改变入口不一定绕过PWRKEY。
  增量补充（2026-10-31整理）：2026-10-28上墙咨询：只有220V时使用隔离稳压AC-DC 5V，而不是仅输出交流的变压器；可走H3-2 5V_IN、19或20 GND，无需占Type-C。H3-4 3V3_OUT不能灌5V；按实板核对，禁止市电直接接入，由电工处理绝缘、暗盒散热及固定。
- **相关报错/日志**：批量实施前应核对当前硬件版本与排针载流、满载温升。

### 原生 GPIO 很紧张，能否增加带按压的滚轮
- **客户问题/现象**：认为IO已全部占用，无法接EC11编码器。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B、TCA9554。
- **根因**：原生GPIO紧张，但H3提供TCA9554扩展的EXIO0～EXIO7；INT似乎未接主控，只能轮询。
- **回复内容（解决方法）**：可将A/B/SW接EXIO0/1/2，公共端接GND，各用约10kΩ上拉到3.3V；TCA9554地址通常0x20，通过方向寄存器0x03和输入寄存器0x00读取，2～5ms轮询并做10～20ms消抖。高速滚轮怕漏步时可把A/B接GPIO20/19，但会占用原生USB D-/D+。
- **相关报错/日志**：不要上拉到5V；不建议使用GPIO0作按压键，复位时会影响下载模式。

### 16MB Flash 的固件上传上限是多少，OTA 会怎样影响
- **客户问题/现象**：客户询问可上传固件的最大容量。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B、16MB Flash、Arduino Partition Scheme/ESP-IDF分区表。
- **根因**：物理Flash总容量不等于单个App分区；bootloader、分区表、NVS/资源及OTA镜像会占空间。
- **回复内容（解决方法）**：准确上限按实际partitions.csv或Arduino分区方案，并检查生成BIN完整大小。无OTA且App从0x10000到16MiB末端的理论空间为0xFF0000字节、15.9375MiB，仅计算示例，不是本板默认方案；双App OTA每槽需再扣数据分区，一般小于8MiB。若App槽3MiB则不能因Flash16MB就上传更大App；资源/签名及安全配置也须计入真实镜像。改分区前确认数据备份与固件/OTA布局配套。
- **相关报错/日志**：🔍 缺客户当前分区，不能给固定默认最大值；已区分MiB与十进制MB。来源：2026-11-03《查询4B固件上传上限》，本次逐条读取原聊天；资料/源码分析与实机结果分开记录。

## 其他问题

### UART 使用 GPIO36/37 后 UI 闪屏或黑屏
- **客户问题/现象**：认为GPIO36/37空闲，配置Serial2后LCD异常。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B、ESP32-S3-WROOM-1-N16R8。
- **根因**：GPIO36/37是8MB Octal PSRAM的DQ7与DQS/DM；UART重配后破坏PSRAM总线，LVGL显存和DMA随之异常。原理图中的“模组物理焊盘37/36”并不等于GPIO37/36。
- **回复内容（解决方法）**：不要使用GPIO33～37作普通GPIO。可按实际资源改用GPIO44(RX)/43(TX)，但它们与CH343P/UART0共线，外接时避免双端同时驱动，并可把日志改走原生USB CDC/JTAG。只改引脚复测，若黑屏消失即可确认冲突。
- **相关报错/日志**：典型错误配置：`Serial2.begin(115200, SERIAL_8N1, 36, 37)`。

### H3-2 输入 5V 不能启动，J1 输入却能启动
- **客户问题/现象**：扩展口供电失败，怀疑电路错误。
- **涉及产品/型号**：ESP32-S3-Touch-LCD-4B。
- **根因**：H3-2/VBUS与USB供电本应等效，常见是引脚数错、电源压降、线阻、PWR未触发或焊接问题；若J1是主板PH2.0，它是3.7V锂电池口，不是5V输入。
- **回复内容（解决方法）**：断开USB和电池，确认H3-2与H3-20；用短粗线和有2A余量的5V源，上电测H3-2是否掉到4.5V以下并短按PWR，再测H3-4是否有3.3V。断电测H3-2与USB VBUS同网、H3-20与GND导通。若J1为主板电池口，立即停止输入5V，避免损坏AXP2101和电池路径。
- **相关报错/日志**：无。
