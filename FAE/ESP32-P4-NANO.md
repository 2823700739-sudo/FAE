# ESP32-P4-NANO

### 5V 供电下最大输入电流是多少
- **客户问题/现象**：询问板卡的5V最大输入电流。
- **涉及产品/型号**：ESP32-P4-NANO。
- **根因**：官方未公布整板明确“最大输入电流”；PoE配套资料的5V/2.5A是供电能力参考，原理图中的“3A MAX”是3.3V稳压输出能力。
- **回复内容（解决方法）**：⚠️ 建议按5V、至少2.5A配置电源；使用5V/3A电源也可以，板卡只按负载取电，关键是不能超过5V。实际消耗取决于屏幕、摄像头、USB和音频外设，需要实测。
- **相关报错/日志**：无。

### 裸屏背光需要 9V/40mA，板上能否直接驱动
- **客户问题/现象**：希望用板载DSI口驱动6颗LED串联的裸屏背光。
- **涉及产品/型号**：ESP32-P4-NANO。
- **根因**：板卡只向屏幕端提供5V，没有集成9V/40mA升压恒流背光驱动；微雪配套屏的背光电路在屏幕板端。
- **回复内容（解决方法）**：需外接5V输入、40mA恒流、输出范围覆盖9V并留余量的升压型LED驱动器；不要把裸屏背光直接接开发板5V或GPIO。
- **相关报错/日志**：无。

### 能否使用 OV3660 摄像头
- **客户问题/现象**：询问OV3660能否接板载摄像头排线。
- **涉及产品/型号**：ESP32-P4-NANO、OV3660。
- **根因**：板载插座是2-lane MIPI-CSI，官方适配OV5647；常见OV3660模组是8位DVP并行接口。
- **回复内容（解决方法）**：不能经板载CSI插座直接使用。理论上可从GPIO自定义DVP接线，但需约14根信号、自制转接板、完整GPIO配置和ESP-IDF驱动开发；若追求快速稳定，使用树莓派接口OV5647。
- **相关报错/日志**：⚠️ 本地历史无P4-NANO+OV3660实测案例。

### 能否直连 7inch DSI LCD (C)，触摸和背光是否可用
- **客户问题/现象**：询问 7inch DSI LCD (C) 能否直插 ESP32-P4-NANO 的 DSI 接口，是否需要转接板，以及触摸和背光能否工作。
- **涉及产品/型号**：ESP32-P4-NANO、7inch DSI LCD (C)、ESP32-P4 rev v3.x。
- **根因**：显示链路使用标准 15Pin FFC/DSI，可直接连接；但屏幕还需要独立 5V 供电以及 I2C 来控制触摸和背光。官方 BSP 将该屏标记为测试通过，但明确要求 ESP32-P4 rev v3.0 及以上，rev v1.3 不支持。
- **回复内容（解决方法）**：断电后用 15Pin FFC 从 NANO 的 DSI 口直连屏幕，无需 DSI 转接板，并核对连接器触点方向。另接 `5V→5V`、`GND→GND`、`SDA→GPIO7`、`SCL→GPIO8`；使用余量充足的 5V 电源。menuconfig 中选择 `Board Support Package (ESP32-P4) → Display → Select LCD type → Waveshare 7inch DSI LCD (C)`，可用 BSP 接口控制背光，触摸采用 GT911 驱动。购买或调试前先通过 esptool/启动日志确认芯片为 rev v3.x，并设置 `CONFIG_ESP_REV_MIN_FULL=300` 或更高。
- **相关报错/日志**：⚠️ rev v1.3 即使物理接口能插入，官方 BSP 也不支持该屏；屏幕典型电流约为背光开启 500mA、关闭 100mA。

### P4 芯片从 v1 换成 v3 时需补焊 R42
- **客户问题/现象**：询问 ESP32-P4 从 v1.x 更换为 v3.x 时需要在哪里加焊电阻，以及该电阻的作用。
- **涉及产品/型号**：ESP32-P4-NANO、ESP32-P4 rev v1.x/v3.x。
- **根因**：P4 v1.0/v1.3 的封装 54 脚为 NC，v3.0 以后改为 `VDD_HP_1`。本板预留 R42，把第 54 脚连接到约 1.2V 的 `ESP_VDD_HP` 核心电源轨；旧版默认不焊是为了兼容 v1 芯片。
- **回复内容（解决方法）**：更换 v3 芯片时在 R42 焊盘安装 0Ω电阻，使 `VDD_HP_1 → R42 → ESP_VDD_HP`。R42 是版本兼容电源跳线，不是限流、分压或上拉电阻，绝对不能把该脚接到 3.3V。不补焊可能使核心电源域供电不完整，导致无法启动、随机重启或负载下死机。量产改版还应按乐鑫 v3 参考设计复核 DCDC 反馈与 USB_DP 等外围，不能把只补 R42 视为完整改版清单。
- **相关报错/日志**：🔍 位号与连接关系基于当前公开原理图；焊接前应核对实际 PCB 版本。

### USB HID、摄像头和 LCD 能否同时运行
- **客户问题/现象**：询问ESP32-P4-NANO-KIT-D能否同时连接USB HID设备、摄像头和LCD并一起运行。
- **涉及产品/型号**：ESP32-P4-NANO、ESP32-P4-NANO-KIT-D、USB Host HID、MIPI-CSI摄像头、MIPI-DSI LCD。
- **根因**：USB OTG、MIPI-CSI和MIPI-DSI属于独立外设，硬件上可以并行；但三个独立示例不能直接拼接，摄像头SCCB与LCD触摸/背光等还可能共享I2C，性能和供电也需统一规划。
- **回复内容（解决方法）**：在同一ESP-IDF工程中统一初始化USB Host HID、摄像头、LCD及共享I2C；键盘、鼠标或扫码枪接Type-A Host口。HID带宽通常不是瓶颈，帧率主要取决于摄像头分辨率/格式、LCD刷新、PSRAM缓冲和图像处理。⚠️ 建议使用稳定5V、至少2.5A电源；高耗电USB设备使用自供电Hub。
- **相关报错/日志**：🔍 官方已验证摄像头加LCD，但暂无KIT-D将HID、摄像头和LCD三者合并的完整官方例程，需实机压力测试。

### PoE 供电时测得 5V 与 GND 短路
- **客户问题/现象**：ESP32-P4-NANO-KIT-D使用PoE模块时，客户测量模块5V与GND认为短路；板卡Type-C和已验证PoE模块供电均正常，客户侧主要差异是网线。
- **涉及产品/型号**：ESP32-P4-NANO、ESP32-P4-NANO-KIT-D、IEEE 802.3af PoE模块、网线。
- **根因**：蜂鸣档短响可能只是5V轨大电容充电，并非真实短路。若板卡和模块分别正常而仅客户网线异常，优先怀疑非八芯、压接/线序错误、线对短路、铜包铝或过细长线导致压降、PoE协商失败或交换机保护；普通断线通常不会让5V输出持续硬短路。
- **回复内容（解决方法）**：完全断电并拔掉网线、USB和外设，把PoE模块与主板分离，分别用电阻档观察5V-GND约10秒：阻值由低逐步升高多为电容充电，持续约0～2Ω才像真实短路。检查模块方向、排针错位、弯针、锡渣和螺柱；再用确认正常的八芯CAT5e/CAT6短成品线、标准IEEE 802.3af端口复测，并用网线测试仪检查1～8脚。裸板正常、接屏后异常时重点检查网线压降和PoE功率余量。
- **相关报错/日志**：配套PoE模块参考输入37～57V、输出5V/2.5A；⚠️ 非标准被动PoE、错线或进水网线可能触发保护或损坏模块。

### 能否采集模拟电压，是否需要外置 ADC
- **客户问题/现象**：询问开发板能否把外部模拟电压转换为数字量，以及是否必须增加ADC。
- **涉及产品/型号**：ESP32-P4-NANO、GPIO20/21/22、ADC1_CH4/5/6。
- **根因**：ESP32-P4内置12位ADC，NANO已引出GPIO20/21/22，可直接采集一般模拟电压；Flash或GPIO数字功能与ADC用途不同。P4没有通用模拟电压输出DAC。
- **回复内容（解决方法）**：模拟信号接GPIO20、21或22之一并共地，使用ESP-IDF ADC校准驱动读取；可配置衰减，最高档测量范围约0～3.3V，原始12位值通常为0～4095，最大采样率约100kSPS。5V、0～10V或负电压必须先分压、限流或运放调理；高精度、低噪声、差分、更高速或更宽量程时再选外置ADC。若需求是输出模拟电压，则使用外置DAC或PWM加低通滤波。
- **相关报错/日志**：GPIO输入绝不能超过其允许电压；🔍 实际可测上限、线性度和误差应按所选衰减与ADC校准结果确认。
