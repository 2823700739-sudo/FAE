# ESP32-P4-WIFI6-Touch-LCD-4.3

### RTC 是芯片内部还是独立芯片，断电为何不保持时间
- **客户问题/现象**：询问 RTC来源，装电池后断电时间仍丢失。
- **涉及产品/型号**：ESP32-P4-WIFI6-Touch-LCD-4.3。
- **根因**：板上没有独立 RTC芯片；RTC BAT接 P4内部 `VDD_BAT/ESP_VBAT`。VBAT功能默认需软件启用，且运行中突然断电不自动切换，需先进入Deep-sleep。
- **回复内容（解决方法）**：启用 `CONFIG_ESP_VBAT_INIT_AUTO=y` 和可充电电池选项；掉电前进入Deep-sleep。启动代码不要每次覆盖时间。RTC口按要求使用可充电电池，不要用不可充电 CR2032。若需突然断电也可靠守时，增加掉电检测或使用 DS3231等外置RTC。
- **相关报错/日志**：无。

### 40Pin 上的 5V 是输入还是输出
- **客户问题/现象**：希望从40Pin给整板供电。
- **涉及产品/型号**：ESP32-P4-WIFI6-Touch-LCD-4.3。
- **根因**：1脚/3脚直接连接共用 `VCC_5V` 电源母线，不是单向端口。
- **回复内容（解决方法）**：可用稳压5V接1脚或3脚、负极接GND作为输入。建议至少5V/2A，重载可留到5V/3A；不要超过5V或向3V3灌电，也不要同时接多个5V源。若供电后未启动，短按 POWER。按板载丝印确认，不要套用树莓派编号。
- **相关报错/日志**：无。

### MicroSD 冷启动报 0x107/0x106，界面黑屏
- **客户问题/现象**：小智派生工程冷启动时 SD卡初始化失败，随后角色界面黑屏。
- **涉及产品/型号**：ESP32-P4-WIFI6-Touch-LCD-4.3、ESP32-P4 rev v1.3。
- **根因**：失败发生在 FATFS和MP4之前；`0x107`为OCR初始化超时，`0x106`多由异常CSD响应引起。客户工程使用 dirty IDF、自改驱动与恢复逻辑，尚不能判定硬件缺陷。
- **回复内容（解决方法）**：先用干净 ESP-IDF v5.5.5、官方 `05_sdmmc`，对v1.3叠加 `rev1_3.defaults`，禁用Hosted/Wi-Fi后用至少两张FAT32卡做20次冷启动；再测 `10_mp4_player`。仍失败时测试1线、10MHz和稳定电源，并提供完整日志、卡型号、PCB与芯片版本。官方最小例程在多卡上复现后，才按产品级SDMMC问题调查；客户完整小智工程和自改驱动不在常规支持范围。
- **相关报错/日志**：`ESP_ERR_TIMEOUT (0x107)`、`ESP_ERR_NOT_SUPPORTED (0x106)`。

### USB 与电池同时连接时插拔 USB 会重启
- **客户问题/现象**：同时连接 USB 和锂电池时，拔出或重新插入 USB 都会瞬时掉电并重启。
- **涉及产品/型号**：ESP32-P4-WIFI6-Touch-LCD-4.3。
- **根因**：该板 USB/锂电池切换不是无缝 UPS 架构。USB 存在时会关闭电池升压芯片 SCT12A0；拔出 USB 后升压芯片才重新启动。软启动约 11ms，板载储能不足以在高负载下维持 Core_5V；插入 USB 时也可能在 USB 电压完全稳定前关闭电池升压，造成瞬时掉电。
- **回复内容（解决方法）**：若单独 USB、单独使用电量充足的 3.7V 锂电池都稳定，仅在 USB 插拔瞬间重启，则大概率属于电源架构特性，而非软件或板卡损坏。需要不断电运行时，应外接带 power-path/UPS 的电源管理模块；不建议直接在 5V 上盲目并联大电容，以免产生浪涌或反灌。可用示波器同时观察 USB 5V、电池升压 5V 与 Core_5V，并结合 brownout/复位日志确认。
- **相关报错/日志**：⚠️ 产品页仅说明电池接口支持充放电，没有承诺 USB/电池无缝切换。

### 40Pin 能否使用杜邦线，长期连接应选什么方案
- **客户问题/现象**：询问背面 40Pin 是否可以用杜邦线连接，以及长期使用时推荐何种连接方式。
- **涉及产品/型号**：ESP32-P4-WIFI6-Touch-LCD-4.3。
- **根因**：板载接口为 2.54mm、2×20 排座，开发调试时可用公头杜邦线；普通单根杜邦线没有锁止和应力固定，不适合振动、拉扯或长期运行。USB 差分信号也不适合经普通杜邦线传输。
- **回复内容（解决方法）**：短期调试可使用公头杜邦线。长期使用优先选择 2×20 公排针转接板或定制底板，并用铜柱固定；必须使用线束时，应转成带锁连接器并做拉力固定。`USBD_N/USBD_P` 应采用短距离受控差分布线或专用 USB 线。若经 40Pin 的 5V/GND 给整板供电，应使用稳定电源和足够线径，避免同时接入多个 5V 源。
- **相关报错/日志**：普通杜邦线长期使用可能出现松动、接触不良、瞬时掉电或高速 USB 枚举失败。
