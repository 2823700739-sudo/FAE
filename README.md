# Crystal FAE 知识库

这是用于整理微雪电子（Waveshare）产品技术支持问题的 Obsidian Vault。

## 目录结构

```text
Crystal/
├─ AGENTS.md                  # Agent 维护与证据规范
├─ README.md                  # 仓库说明
└─ FAE/
   ├─ 00-FAE知识库索引.md      # 总索引与整理边界
   ├─ P4.md / S3.md / C5.md   # 系列导航
   ├─ 产品/                    # 仅限可确认的微雪具体产品/SKU
   ├─ 通用/                    # 与微雪产品支持直接相关的通用问题
   └─ 资源/
      ├─ 图片/<产品型号>/       # 照片、截图、规格证据
      ├─ 资料/<产品型号>/       # 官方文档、原理图、PDF等
      ├─ 日志/<产品型号>/       # 串口、构建、配置等诊断资料
      └─ 画布/                  # Obsidian Canvas
```

所有产品问答从 [[FAE/00-FAE知识库索引]] 进入。维护前先阅读 [[AGENTS]]；有官方链接或相关资料时必须在条目中记录来源，不能只保留文字结论。

## 知识库更新与云端同步

按用户2026-11-25授权，每次FAE补充完成并校验后，自动提交、推送到 [GitHub FAE仓库](https://github.com/2823700739-sudo/FAE) 的 `main`。仅同步知识库、相关附件和维护规范；Obsidian/Claudian会话、插件及凭据保持本地。遇到远端更新先核对整合，不强推；最终以远端提交哈希确认同步。
